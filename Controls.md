Game controls reproduced from the original inlay:

**Team-selection and graph screens**

- `6` — move arrow up
- `7` — move arrow down

**Interactive pit stop**

- `Q` — move up
- `Z` — move down
- `I` — move left
- `P` — move right
- `N` — execute the selected manoeuvre

**While a race is running**

- `P` — request a pit stop
- `C` — cancel a pit-stop request
- `F` — full race graphics
- `H` — highlights only
- `G` — gambling option
- `S` — request to save the game
